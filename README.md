# GymHub

Система администрирования спортивного комплекса.

## О проекте

GymHub — backend-приложение для управления спортивным комплексом. Проект разрабатывается как единая система, позволяющая администрировать инфраструктуру комплекса, учитывать клиентов, абонементы и посещения, а также управлять расписанием занятий.

Основная задача проекта — объединить административные процессы спортивного комплекса в одном приложении.

Проект разрабатывается в рамках личного обучения и практического применения технологий Java Backend.

## Планируемые возможности

- **Управление спортивным комплексом** — создание и редактирование информации о комплексе, управление залами и функциональными зонами.
- **Управление клиентами** — добавление клиентов, хранение информации о них.
- **Абонементы** — фиксация продаж, управление абонементами и сроками их действия.
- **Расписание** — создание и редактирование расписания занятий.
- **Запись на занятия** — запись клиентов на групповые и индивидуальные занятия.
- **Учёт посещений** — фиксация посещений и сбор статистики.
- **Загрузка залов** — отображение текущей занятости и статистики использования помещений.

## Архитектура

Планируемый архитектурный подход — модульный монолит на Spring Boot.

Основные принципы:
- разделение приложения на функциональные области;
- разделение ответственности между слоями приложения;
- взаимодействие с базой данных через Spring Data JPA;
- использование DTO для передачи данных через REST API;
- централизованная обработка ошибок;
- управление структурой БД через Flyway.

## Текущая реализация

На текущем этапе реализована базовая функциональность управления информацией о спортивном зале.

### Backend

- REST API для управления информацией о зале.
- Создание, получение, обновление и удаление данных.
- Валидация входящих запросов.
- Обработка ошибок.
- Документация API через Swagger / OpenAPI.

### Frontend

Разработана базовая демонстрационная страница для взаимодействия с REST API.

Интерфейс предназначен для проверки основных операций и демонстрации работы backend-приложения.

 URL                                         | Описание страницы            |
|---------------------------------------------|------------------------------|
| `http://localhost:8080/index.html`          | главная страница             |
| `http://localhost:8080/profile.html?id={id}` | страница администратора зала |


### Тестирование

- Автоматизированные тесты REST-контроллера.
- Покрытие тестами — около 90% для текущего контроллера.
- Проверка основных сценариев работы API, валидации и обработки ошибок.

### CI

Настроен GitHub Actions для автоматического запуска Maven-тестов.

Workflow запускается при:
- отправке изменений (push) в ветки `main` и `develop`;
- создании Pull Request в ветки `main` и `develop`.

## Запуск проекта

Пока недоступен запуск в Docker

### Требования

- Java 21
- Maven
- PostgreSQL

### Локальный запуск

1. Клонировать репозиторий:

   ```bash
   git clone <REPOSITORY_URL>
   ```

2. Перейти в директорию проекта:

   ```bash
   cd GymHub
   ```

3. Настроить подключение к базе данных и необходимые переменные окружения.

4. Запустить приложение:

   ```bash
   mvn spring-boot:run
   ```
