## О проекте

GymHub — это SaaS-платформа, которая позволяет фитнес-клубам управлять клиентами, тренерами, расписанием тренировок и абонементами.

### Основные роли

- User — клиент платформы
- Trainer — тренер фитнес-клуба
- Owner — владелец фитнес-клуба
- System Admin — администратор платформы

## Изученные технологии

### Sprint 1

#### Technology

Что изучено:
- Flyway;
- Swagger/OpenAPI; 
- Spring Security;
- JWT-аутентификация;
- работа с переменными окружения в Spring Boot.

#### Что реализовано 
<b>База данных и миграции</b>
- настроено подключение PostgreSQL;
- реализована первая миграция Flyway;
- создана базовая сущность пользователя.
  
<b>Регистрация пользователя</b>

Реализована логика регистрации нового пользователя:

- создан DTO для входящих данных;
- реализована валидация email;
- создана кастомная аннотация для проверки сложности пароля;
- настроено хеширование паролей через BCrypt;
- реализован endpoint регистрации;
- настроена глобальная обработка ошибок через GlobalExceptionHandler.

<b>Аутентификация и авторизация</b>

Реализован полный цикл аутентификации пользователя:

- создан DTO для запроса авторизации;
- создан DTO ответа с JWT-токеном;
- реализован CustomUserDetailsService;
- настроен AuthenticationManager;
- реализован сервис генерации JWT;
- реализован сервис проверки JWT;
- создан JwtFilter для обработки токенов из заголовка Authorization;
- настроена защита endpoint'ов через Spring Security;
- реализовано сохранение аутентифицированного пользователя в SecurityContext.

Для проверки учетных данных используется AuthenticationManager и PasswordEncoder.

Пароли пользователей хранятся в базе данных только в виде BCrypt-хешей.

<b> Swagger </b>

Swagger используется для:

- документирования API;
- тестирования endpoint'ов регистрации;
- тестирования endpoint'ов авторизации;
- получения JWT и проверки защищенных ресурсов.

<b> Тестирование </b>

Проведено первичное тестирование приложения:

- написаны unit-тесты сервисного слоя;
- протестированы регистрация и авторизация через Postman;
- подготовлена Postman-коллекция для дальнейшей интеграции в CI/CD.

#### Что было изучено:

- работа Flyway и миграций;
- устройство цепочки фильтров Spring Security;
- процесс аутентификации через AuthenticationManager;

#### Основные сложности:
<b>1. Проблема:</b>

Приложение запускалось из IDE, но не запускалось из консоли из-за отсутствия переменных окружения.

Решение:
```
spring:
  config:
    import: optional:file:.env[.properties]
```
Это позволило использовать локальный файл .env без необходимости задавать переменные вручную.

<b>2. Проблема:</b>

Запросы из Postman блокировались механизмом CSRF-защиты.

Решение:
```
http.csrf(csrf -> csrf.disable());
```
После перехода на JWT-аутентификацию CSRF-защита для REST API была отключена.

### Локальный запуск
Создать файл .env по примеру .env.example

```java
git clone https://github.com/DarinaLeonoff/GymHub.git
cd gymhub

mvn spring-boot:run
```
