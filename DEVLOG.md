## О проекте

GymHub — это SaaS-платформа, которая позволяет фитнес-клубам управлять клиентами, тренерами, расписанием тренировок и абонементами.

### Основные роли

- User — клиент платформы
- Trainer — тренер фитнес-клуба
- Owner — владелец фитнес-клуба
- System Admin — администратор платформы

## Интересные инженерные решения

### ADR-001. Роли пользователей

Для MVP роли реализованы через Enum в сущности User.

Причина:

- упрощение модели;
- ускорение разработки базовой аутентификации.

В дальнейшем планируется выделение ролей сотрудников залов в отдельную сущность GymStaff.
